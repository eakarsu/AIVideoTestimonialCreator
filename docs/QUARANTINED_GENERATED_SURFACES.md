# Quarantined generated surfaces

The former server mounted a broad generated catalog, including `gapNoVisionBasedBodyLanguageAnalysisBeyondEmotion`, direct generic chat-completion tools, stub publishers, demo registration, and routes backed by ad hoc tables. Those files remain only as provenance while existing owners decide whether to delete or archive them; `backend/server.js` does not mount them.

The supported body-language endpoint accepts consented pose observations, reports only descriptive camera-facing/posture/gesture aggregates, records data and model-card provenance, and explicitly prohibits emotion, truthfulness, personality, protected-trait, or mental-health inference. It cannot approve a testimonial. The generated page is therefore not evidence of completion and is outside the supported runtime boundary.
